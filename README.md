# Maison Saffron — Restaurant Digital Menu

A polished, responsive restaurant digital menu built with **HTML5, CSS3 and vanilla JavaScript**.

## Features

- Elegant restaurant landing page and menu cards
- Categories and instant search (accent-insensitive)
- Detailed dish previews
- Add to cart, quantity controls, subtotal
- Cart persistence with LocalStorage
- Responsive mobile order bar and drawer
- Keyboard-friendly controls and lightweight transitions
- Demo-only checkout (no real purchase, payments, kitchen or server integration)

## Launch

Open `index.html` in a browser, or serve the folder with a local static server (`python -m http.server 5500`). No build tools or dependencies are needed.

## Deployment

Upload the folder to GitHub, then import the repository into Vercel. Use **Other** as the framework preset with no build command. The output directory is the project root.

## Portfolio notes

This is a concept website for an imaginary restaurant. All dish names, prices, social handles, and addresses are demonstration content. Restaurant photography loads from Unsplash and fonts load from Google Fonts; an internet connection is required for those assets. If photos fail, food-themed placeholders are shown for dish cards.

## Optional future features
